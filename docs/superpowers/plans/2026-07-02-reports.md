# Plano: relatorios guiados e personalizados

## Contexto

O usuario aprovou o desenho: primeiro investigar na tela, depois gerar o relatorio com o mesmo recorte se necessario. A correlacao ja esta madura e nao deve ser duplicada no frontend.

## Passos

1. Registrar o desenho aprovado em documento de especificacao.
2. Estender a API de eventos/timeline para aceitar filtros adicionais usados por relatorios.
3. Criar exportacao CSV baseada nos eventos projetados pela timeline.
4. Criar modulo frontend com definicoes dos relatorios guiados e helpers de filtro.
5. Adicionar testes para os cenarios guiados e montagem de URL.
6. Criar a aba "Relatorios" no frontend com:
   - cards de relatorios guiados;
   - modo personalizado;
   - formulario de filtros;
   - cards executivos;
   - tabela investigativa;
   - exportacao CSV;
   - pre-visualizacao textual do relatorio.
7. Ajustar estilos de forma consistente com a UI operacional existente.
8. Atualizar README com uso dos relatorios.
9. Rodar testes e builds.
